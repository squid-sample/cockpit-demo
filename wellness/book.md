| 书名                 | 作者           | 核心价值                                         |

## 四、资金管理与风险控制（3本）


| 书名                 | 作者         | 核心价值                                |

## 推荐阅读路径

### 第一阶段：建立体系（1-2个月）

```
《日本蜡烛图技术》→《期货市场技术分析》→《以交易为生》
```

### 第二阶段：攻克心理（1个月）⭐ 最关键

```
《交易心理分析》→《股票大作手回忆录》→《幽灵的礼物》
```

### 第三阶段：资金管理（1个月）

```
《通向财务自由之路》→《海龟交易法则》
```

### 第四阶段：实战打磨（长期）

```
《专业投机原理》→《高胜算操盘》→ 反复回读前三阶段
```

### 第五阶段：补齐配置与认知（与实战并行，1-2个月）⭐

```
《不落俗套的成功》→《投资中最简单的事》→《思考，快与慢》
→《随机漫步的傻瓜》→《对赌》
```

> 交易体系成熟后，尽早开始读这一阶段——它决定你赚到的钱能不能留住。

### 第六阶段：拉长视野（长期穿插阅读）

```
《巴菲特致股东的信》（本地PDF，每年读几篇）→《大空头》
→《金融狂热简史》→《周期》
```

## 阅读提醒

- 经典书籍多为美股/期货市场案例，A股应用时需结合涨跌停、T+1、政策市等特点调整，不可生搬硬套。
- 技术书解决"看懂"，心理书解决"做到"，资金管理书解决"活久"，配置书解决"留住"。四类缺一不可。
- **书只占交易能力的约30%**：看懂≠做到。验收标准是自己的交易系统、回测数据、50笔以上纪律记录和正收益的年度结算，而不是读完的本数。
- 心理类和股东信要反复读：每次大亏后重读，会看到之前完全没看懂的句子。
