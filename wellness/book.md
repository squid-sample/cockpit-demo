# 炒股技术相关书籍推荐

> 按学习路径分类整理，配合现有交易规则体系（ATR止损/斐波那契/RSI/EMA/裸K/多时间框架）使用。
> 更新日期：2026-10-09

## 一、入门基础（必读2本）


| 书名                 | 作者         | 核心价值                     | 难度   |
| ---------------------- | -------------- | ------------------------------ | -------- |
| 《日本蜡烛图技术》   | 史蒂夫·尼森 | K线形态圣经，裸K交易者必读   | ★★   |
| 《期货市场技术分析》 | 约翰·墨菲   | 技术分析百科全书，体系最完整 | ★★★ |

**建议**：尼森的书精读，墨菲的书当字典查。

## 二、技术分析经典（进阶3本）


| 书名                   | 作者             | 核心价值                             |
| ------------------------ | ------------------ | -------------------------------------- |
| 《技术分析（第五版）》 | 马丁·普林格     | 趋势/周期/量价关系讲得最透           |
| 《股市趋势技术分析》   | 爱德华兹/迈吉    | 道氏理论+形态学鼻祖，"技术分析之父"  |
| 《以交易为生》         | 亚历山大·埃尔德 | 三重滤网系统，技术+心理+资金三位一体 |

## 三、交易心理学（重点4本）⭐


| 书名                 | 作者           | 核心价值                                         |
| ---------------------- | ---------------- | -------------------------------------------------- |
| 《交易心理分析》     | 马克·道格拉斯 | **必排第一**。讲"概率思维"和"纪律执行"的最佳著作 |
| 《股票大作手回忆录》 | 埃德温·勒菲弗 | 利弗莫尔一生，交易心理+趋势交易的源头            |
| 《自律的交易者》     | 马克·道格拉斯 | 《交易心理分析》前传，讲如何建立交易信念         |
| 《幽灵的礼物》       | 阿瑟·辛普森   | 3条规则重塑交易认知，薄但精辟                    |

**重点推荐《交易心理分析》**：已有的止损/冷却/分批规则，这本书会告诉你为什么这些规则难以执行，以及如何让执行变成本能。

## 四、资金管理与风险控制（3本）


| 书名                 | 作者         | 核心价值                                |
| ---------------------- | -------------- | ----------------------------------------- |
| 《资金管理方法》     | 瑞·巴罗斯   | 仓位管理数学原理                        |
| 《通向财务自由之路》 | 范·K·撒普  | R乘数、期望值、头寸规模，系统化交易必读 |
| 《海龟交易法则》     | 柯蒂斯·费思 | 完整交易系统案例（入场+止损+仓位+退出） |

**与现有交易规则的对应**：

- "单笔风险≤2%" = 撒普的R乘数思想
- "分批建仓≥0.5ATR间距" = 海龟法则的加仓逻辑
- "48h冷却" = 道格拉斯讲的情绪隔离

## 推荐阅读路径

### 第一阶段：建立体系（1-2个月）

```
《日本蜡烛图技术》→《期货市场技术分析》→《以交易为生》
```

### 第二阶段：攻克心理（1个月）⭐ 最关键

```
《交易心理分析》→《股票大作手回忆录》→《幽灵的礼物》
```

### 第三阶段：资金管理（1个月）

```
《通向财务自由之路》→《海龟交易法则》
```

### 第四阶段：实战打磨（长期）

```
《专业投机原理》→《高胜算操盘》→ 反复回读前三阶段
```

## 终极3本（如果只读3本）

1. **《交易心理分析》** — 解决"执行不了规则"的问题
2. **《日本蜡烛图技术》** — 解决"看不懂盘面"的问题
3. **《通向财务自由之路》** — 解决"仓位和风险管理"的问题

## 阅读提醒

- 经典书籍多为美股/期货市场案例，A股应用时需结合涨跌停、T+1、政策市等特点调整，不可生搬硬套。
- 技术书解决"看懂"，心理书解决"做到"，资金管理书解决"活久"。三类缺一不可。
